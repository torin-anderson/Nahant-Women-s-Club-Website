This is a website for the Nahant Women's Club! Started on 9/22/26

## Tech Stack

* **Frontend:** React
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Build Tool:** Vite
* **Runtime:** Node.js
* **Hosting:** Netlify
* **Domain:** Custom domain

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
